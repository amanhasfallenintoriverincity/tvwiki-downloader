# tvwiki-downloader

티비위키 임베드 영상을 MP4로 다운로드하는 Electron 데스크톱 앱입니다. 링크를 붙여넣으면 키 회수부터 복호화, 변환까지 한 번에 처리합니다.

## 시작하기

### 요구사항

- Node.js 20 이상 (Node 26에서 검증됨)
- 인터넷 연결

시스템에 ffmpeg나 python을 설치할 필요가 없습니다. 다운로드와 복호화는 Node 네이티브 모듈로 처리하고, 영상 변환은 앱에 포함된 `ffmpeg-static`을 사용합니다.

### 설치

```bash
git clone <저장소 URL>
cd tvwiki-desktop
npm install
```

설치 후 테스트를 실행해 모든 것이 정상인지 확인할 수 있어요.

```bash
npm test
```

12개 테스트가 모두 통과하면 준비 완료입니다.

### 첫 실행

```bash
npm start
```

앱 창이 열리면 티비위키 영상 링크를 붙여넣고 다운로드 시작 버튼을 누르면 됩니다.

## 사용법

1. 티비위키 영상 페이지 URL을 복사해 입력창에 붙여넣습니다.
2. 필요하면 저장 폴더를 변경합니다. 기본값은 시스템 다운로드 폴더(한국어 로케일에서는 `~/다운로드`)입니다.
3. 검증만 체크하면 앞의 2개 세그먼트만 다운로드해 파이프라인을 검증합니다. 전체 다운로드 전에 확인하고 싶을 때 유용합니다.
4. 병렬 수 슬라이더로 동시 다운로드 수를 조정합니다. 기본값 8, 최대 24까지 가능합니다.
5. 다운로드 시작 버튼을 누릅니다.

진행 상태는 단계 표시와 로그로 확인할 수 있어요. 각 단계가 완료될 때마다 표시가 갱신되고, 세그먼트별 진행률과 속도가 실시간으로 나타납니다. 완료 후 저장 위치 열기 버튼을 누르면 파일이 저장된 폴더가 열립니다.

### CLI로 파이프라인 검증

GUI를 열지 않고 명령줄에서 바로 검증할 수 있습니다.

```bash
npm run probe -- "https://tvwiki47.net/movie/32005/406777415"
```

이 명령은 세션 확보부터 키 회수, 매니페스트 파싱, 세그먼트 다운로드까지 전체 흐름을 실행하지만 실제 파일 저장은 하지 않습니다. 파이프라인이 정상 동작하는지 확인할 때 사용합니다.

## 동작 원리

다운로드는 세 단계로 진행됩니다.

### 1. 세션 확보

숨겨진 Electron 창이 티비위키 페이지를 로드합니다. 페이지가 AJAX로 주입하는 임베드 URL을 포착합니다. 임베드 호스트는 `player.bunny-frame.online`이며, 이 URL 없이는 플레이어에 접근할 수 없습니다.

### 2. 키 회수

두 번째 숨겨진 창이 임베드 페이지를 로드하고, 사이트 플레이어가 복호화한 AES 키를 브라우저 메모리에서 회수합니다. 키는 `window.tvchakArtPlayer._tvchakHls.levels[0].details.fragments[0].decryptdata.key`에 16바이트 `Uint8Array`로 저장되어 있습니다.

복호 로직은 WASM으로 구현되어 있어 Node로 이식할 수 없습니다. 그래서 브라우저가 복호화한 키를 직접 회수하는 방식을 사용합니다.

### 3. 다운로드

회수한 키로 매니페스트를 재작성하고, 세그먼트를 병렬로 다운로드한 뒤 AES-128-CBC로 복호화합니다. 마지막으로 `ffmpeg-static`으로 TS 컨테이너를 MP4로 리먹스합니다.

매니페스트의 세그먼트는 `.gif` 확장자로 위장되어 있고, 여러 랜덤 도메인에 분산되어 있습니다. downloader 모듈이 이를 자동으로 처리합니다.

## 주의사항

- **토큰 만료**: 임베드 토큰은 수 분, 매니페스트와 키 토큰은 약 2시간 유효합니다. 다운로드가 실패하면 다시 시도해 새 세션을 확보하세요.
- **저장 위치**: 기본 저장 위치는 시스템 다운로드 폴더입니다. 한국어 로케일에서는 `~/다운로드`에 저장됩니다.
- **비트레이트**: 매니페스트는 단일 비트레이트(보통 1080p)만 제공합니다. 화질 선택 기능은 없습니다.
- **세그먼트 구조**: 세그먼트는 `.gif` 확장자로 위장된 랜덤 도메인에 분산되어 있습니다. 앱이 자동으로 처리하므로 신경 쓰지 않아도 됩니다.

## 면책 경고

이 도구는 개인 백업 목적으로 제공됩니다. 다운로드한 영상의 저작권 책임은 사용자에게 있습니다. 저작권법이 허용하는 범위 내에서만 사용하세요.
