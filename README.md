# tvwiki-downloader

티비위키 임베드 영상을 MP4로 저장하는 Electron 데스크톱 앱입니다. 링크를 붙여넣으면 에피소드 목록을 먼저 보여주고, 원하는 화만 골라 내려받습니다. 키 회수부터 복호화, MP4 변환까지 앱이 한 번에 처리하므로 별도 도구를 설치하지 않아도 됩니다.

## 주요 기능

- **링크 한 줄로 목록 조회**: 시즌 링크를 붙여넣으면 전체 에피소드 목록을 먼저 불러옵니다. 다운로드는 목록을 확인한 뒤에 시작합니다.
- **선택 다운로드**: 원하는 에피소드만 체크해서 내려받습니다. 시즌 전체를 받을 필요가 없습니다.
- **다운로드 취소**: 진행 중인 다운로드를 언제든 멈춥니다. 취소하면 임시 파일을 정리합니다.
- **도구 설치 불필요**: ffmpeg나 python을 따로 깔지 않아도 됩니다. 복호화는 Node 네이티브 모듈이, 변환은 앱에 포함된 `ffmpeg-static`이 담당합니다.

## 시작하기

### Windows에서 실행하기

Node.js를 설치하지 않고 바로 실행하려면 `release` 폴더에서 다음 파일 중 하나를 사용합니다.

- `TVWiki Downloader-Setup-1.0.0-x64.exe`: 설치 경로와 바로가기를 지정할 수 있는 설치형 파일입니다.
- `TVWiki Downloader-Portable-1.0.0-x64.exe`: 설치하지 않고 바로 실행하는 무설치형 파일입니다.

이 빌드는 64비트 Windows용입니다. 코드 서명 인증서를 적용하지 않았으므로 Windows SmartScreen이 처음 실행할 때 경고할 수 있습니다. 직접 빌드한 파일인지 확인한 뒤 **추가 정보 → 실행**을 선택하세요.

### 요구사항

- Node.js 20 이상 (Node 26에서 검증했습니다)
- 인터넷 연결

### 설치하기

저장소를 내려받고 의존성을 설치합니다.

```bash
git clone <저장소 URL>
cd tvwiki-desktop
npm install
```

설치한 뒤 테스트를 돌리면 파이프라인이 정상인지 미리 확인할 수 있습니다.

```bash
npm test
```

16개 테스트가 모두 통과하면 준비가 끝났습니다.

### 실행하기

```bash
npm start
```

앱 창이 열리면 티비위키 링크를 붙여넣고 목록을 불러온 뒤 다운로드를 시작합니다.

## 사용법

1. 티비위키 시즌 페이지 URL을 복사해 입력창에 붙여넣습니다. 붙여넣으면 에피소드 목록을 자동으로 불러옵니다.
2. 내려받을 에피소드를 체크합니다. 처음에는 전체가 선택되어 있으니, 필요 없는 화의 체크를 해제하면 됩니다.
3. 필요하면 저장 폴더를 바꿉니다. 기본값은 시스템 다운로드 폴더이며, 한국어 로케일에서는 `~/다운로드`에 저장합니다.
4. 병렬 수 슬라이더로 동시 다운로드 수를 조정합니다. 기본값은 8, 최대 16까지 올릴 수 있습니다.
5. 전체 흐름을 미리 확인하려면 검증 옵션을 켭니다. 앞의 세그먼트 2개만 받아 파이프라인을 점검하고 실제 파일은 저장하지 않습니다.
6. **선택 다운로드** 버튼을 눌러 다운로드를 시작합니다. 다운로드 중에는 같은 버튼이 **다운로드 취소**로 바뀌므로, 언제든 멈출 수 있습니다.

단계 표시와 로그로 진행 상태를 확인합니다. 각 단계가 끝날 때마다 표시가 갱신되고, 세그먼트별 진행률과 속도가 실시간으로 나타납니다. 다운로드가 끝나면 저장 위치 열기 버튼으로 결과 폴더를 바로 엽니다.

### CLI로 파이프라인 검증하기

GUI를 열지 않고 명령줄에서 바로 파이프라인을 점검합니다.

```bash
npm run probe -- "https://tvwiki47.net/movie/32005/406777415"
```

이 명령을 실행하면 세션 확보, 키 회수, 매니페스트 파싱, 세그먼트 다운로드까지 전체 흐름을 돌리되 파일은 저장하지 않습니다. 파이프라인이 정상 동작하는지 빠르게 확인할 때 사용합니다.

## 동작 원리

다운로드는 세 단계로 진행합니다.

### 1. 세션 확보

숨겨진 Electron 창이 티비위키 페이지를 로드합니다. 페이지가 AJAX로 주입하는 임베드 URL을 이 창이 포착합니다. 임베드 호스트는 `player.bunny-frame.online`이며, 이 URL 없이는 플레이어에 접근할 수 없습니다.

### 2. 키 회수

두 번째 숨겨진 창이 임베드 페이지를 로드하고, 사이트 플레이어가 복호화한 AES 키를 브라우저 메모리에서 회수합니다. 키는 `window.tvchakArtPlayer._tvchakHls.levels[0].details.fragments[0].decryptdata.key`에 16바이트 `Uint8Array`로 들어 있습니다.

복호 로직은 WASM으로 구현되어 Node로 이식할 수 없습니다. 그래서 브라우저가 이미 복호화한 키를 직접 회수하는 방식을 씁니다.

### 3. 다운로드

회수한 키로 매니페스트를 다시 쓰고, 세그먼트를 병렬로 내려받은 뒤 AES-128-CBC로 복호화합니다. 마지막으로 `ffmpeg-static`이 TS 컨테이너를 MP4로 리먹스합니다.

매니페스트의 세그먼트는 `.gif` 확장자로 위장되어 여러 랜덤 도메인에 흩어져 있습니다. downloader 모듈이 이 구조를 자동으로 처리합니다.

## 알아두기

- **토큰 만료**: 임베드 토큰은 수 분, 매니페스트와 키 토큰은 약 2시간 동안 유효합니다. 다운로드가 실패하면 다시 시도해 새 세션을 확보하세요.
- **저장 위치**: 기본 저장 위치는 시스템 다운로드 폴더입니다. 한국어 로케일에서는 `~/다운로드`에 저장합니다.
- **화질**: 매니페스트는 단일 비트레이트(보통 1080p)만 제공합니다. 화질을 직접 고르는 기능은 없습니다.
- **세그먼트 구조**: 세그먼트는 `.gif`로 위장된 랜덤 도메인에 흩어져 있습니다. 앱이 자동으로 처리하므로 신경 쓰지 않아도 됩니다.

## 저작권 안내

이 도구는 개인 백업 목적으로 제공합니다. 내려받은 영상의 저작권 책임은 사용자에게 있습니다. 저작권법이 허용하는 범위에서만 사용하세요.

## 개발 명령

| 명령 | 설명 |
| --- | --- |
| `npm start` | Electron 앱을 실행합니다 |
| `npm test` | 단위 테스트 16개를 실행합니다 |
| `npm run probe -- <URL>` | GUI 없이 파이프라인을 검증합니다 |
| `npm run dist:win` | Windows x64 설치형·무설치형 EXE를 `release`에 만듭니다 |
